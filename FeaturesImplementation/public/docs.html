🔄 Common Workflows

1️⃣ Complete Reservation Workflow

Steps:

  1. Search available rooms (Reservations tab)
  2. Create reservation
  3. Process payment (Payments tab)
  4. Check-in guest (Check-In/Out tab)
  5. Generate invoice (Billing tab)

2️⃣ Add New Room

Steps:

  1. Go to Inventory tab
  2. Fill in room details
  3. Click "Add Room"

3️⃣ Daily Operations

Steps:

  1. Check occupancy (Dashboard)
  2. Process check-ins (Check-In/Out)
  3. Post charges (Check-In/Out)
  4. Process check-outs (Check-In/Out)
  5. View revenue report (Reports)
